# Themes

Schema: [`schema/theme.schema.json`](../schema/theme.schema.json)

A theme is token data only: colors, radius, font, blur. Forbidden: `javascript:`, `@import`, remote `url(http…)`, `<script`, IE `expression(`.

Built-in: Midnight, Daylight, High Contrast, AMOLED, plus System mapping via the Daylight/Midnight pair. Community packs use GitHub topic `muck-theme` and a `theme.json` file.

Import from Settings → Themes, or drop JSON into `%APPDATA%\MuckStore\themes`.
